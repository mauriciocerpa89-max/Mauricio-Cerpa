# VerdeVita

Landing page de VerdeVita, creada con HTML y CSS puro.

## Estructura

- `index.html` — página principal
- `style.css` — estilos y diseño responsive
- `IMG/` — imágenes utilizadas por la página

## Ejecutar localmente

Abre `index.html` directamente en el navegador o usa Live Server desde Visual Studio Code.

## GitHub Pages

El proyecto está preparado para publicarse como sitio estático. `index.html` se encuentra en la raíz del repositorio y todas las rutas de recursos son relativas.
